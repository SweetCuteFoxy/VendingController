# VendingIcon — принцип работы

**VendingIcon.kt** — это утилитный объект для отрисовки векторной иконки вендингового автомата с помощью JavaFX Shape. Используется как логотип приложения (на экране входа и в боковом меню).

## Как работает
- Метод `VendingIcon.create(size: Double): Group` возвращает JavaFX Group с набором фигур (`Rectangle`, `Circle`, `Line`), которые вместе образуют стилизованный автомат.
- Все размеры и координаты рассчитываются пропорционально переданному `size`, чтобы иконка выглядела одинаково хорошо при разных размерах (например, 24px и 56px).
- Цвета подобраны так, чтобы иконка была заметной и подходила под светлую и тёмную темы.

## Структура иконки
- **Корпус**: закруглённый прямоугольник (основной цвет автомата)
- **Верхняя панель**: тёмная полоса сверху (брендовая)
- **Витрина**: светлый прямоугольник с двумя полками (имитация товаров)
- **Кнопки**: три цветные кнопки справа (выбор товара)
- **Купюроприёмник**: жёлтый прямоугольник под кнопками
- **Отсек выдачи**: тёмная ниша внизу
- **Ножки**: две маленькие ножки снизу

## Использование
```kotlin
val icon: Group = VendingIcon.create(56.0) // для крупного логотипа
val smallIcon: Group = VendingIcon.create(24.0) // для сайдбара
```

## Где применяется
- **LoginView.kt** — крупная иконка на экране входа
- **MainView.kt** — маленькая иконка в бренде бокового меню

## Преимущества
- Векторная графика: не теряет качество при масштабировании
- Не зависит от внешних файлов (SVG, PNG)
- Легко стилизовать и доработать прямо в коде
